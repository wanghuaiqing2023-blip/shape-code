# shape-code

本项目致力于在 AI 时代重塑代码阅读体验。我们相信，代码不应只是被逐行查看的文本，而应成为一种可以被理解、追踪、对话和重构的思想结构。借助 AI，开发者可以更高效地把握代码脉络，理解源码作者的意图，并以更符合人类直觉的方式阅读、探索和编辑代码。

每一个代码片段都不只是孤立的文本，它可能关联着一个功能、一项需求、一次 bug 修复、一种架构取舍、一套设计模式，甚至是原作者当时的思想观念与决策动机。然而，人类在阅读代码时，直觉和本能往往倾向于先获取表层信息：变量名、函数结构、调用关系和局部实现。这种阅读方式虽然必要，却并不足以帮助开发者快速领悟一个源码仓库真正的本质思想。

代码片段只是整体系统中的一个局部。只有将局部重新放回功能、架构、调用关系、历史演化和设计意图构成的整体之中，我们才能真正理解它。因此，本项目必须支持开发者在局部视角与整体视角之间持续切换：既能深入某一段实现细节，也能随时回到系统全局，理解它在整个源码仓库中的位置、作用和意义。

在 LLM 的使用策略上，本项目应区分“深层理解阶段”和“实际操作阶段”。在项目级分析、架构归纳、上下文压缩和关键决策推理等高难度任务中，应尽量使用顶级大模型，以提升推理准确性；而在日常代码阅读、局部解释、导航辅助和重复性操作阶段，则应优先使用本地模型，以降低成本并提升使用的可持续性。
